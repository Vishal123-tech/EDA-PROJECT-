# ⚡ Pokémon — Exploratory Data Analysis

An exploratory analysis of Pokémon types, generations, legendary status, and battle statistics using the classic Pokémon dataset.

![Pokémon EDA overview](./pokemon_eda_overview.svg)

![Pokémon battle-stat comparison](./pokemon_stats_comparison.svg)

## 📌 Project Questions

- How are Pokémon distributed across primary types?
- How do battle statistics vary across generations and types?
- What proportion of the dataset is legendary?
- Which stats are most strongly correlated with total battle strength?

## 🔎 Analysis Covered

- Data inspection, cleaning, and missing-value handling
- Primary and secondary type combinations
- Generation distribution and generation-level average stats
- Legendary versus non-legendary comparisons
- HP, Attack, Defense, Special Attack, Special Defense, and Speed distributions
- Radar-style Pokémon stat comparisons
- Type heatmaps, pairplots, and correlation analysis
