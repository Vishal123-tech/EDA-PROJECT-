# Stack Overflow Developer Survey Analysis

A structured exploratory data analysis project built with Python and Jupyter Notebook to understand developer demographics, technology adoption, career experience, compensation patterns, and work-related preferences.

## Project Overview

This project turns Stack Overflow Developer Survey responses into a reproducible analysis workflow. The notebooks cover data inspection, preparation, exploratory analysis, visual storytelling, and interpretation of patterns across developer roles, technologies, experience levels, and career outcomes.

## Objectives

- Understand the demographic and professional profile of survey respondents.
- Explore programming languages, databases, platforms, frameworks, and other technologies used or preferred by developers.
- Examine relationships between experience, role, location, compensation, and job satisfaction.
- Identify patterns, differences, and outliers through grouped summaries and visual analysis.
- Document a clear, repeatable data analyst workflow in Jupyter notebooks.

## Notebooks

| Notebook | Purpose |
| --- | --- |
| 01_eda.ipynb | Data inspection, cleaning, missing-value review, descriptive analysis, and exploratory visualizations. |
| 02_analysis.ipynb | Extended analysis of developer trends, technology preferences, career factors, compensation, and other survey relationships. |

## Analysis Workflow

Survey data → Data cleaning → Exploratory analysis → Visualizations → Insights

## Skills Demonstrated

- Python data analysis with pandas and NumPy
- Data cleaning and missing-value analysis
- Descriptive statistics and grouped comparisons
- Exploratory data analysis and visualization
- Relationship analysis across categorical and numerical fields
- Communicating analytical findings through notebooks

## Key Analysis Areas

- Developer demographics and professional experience
- Technology usage and future technology preferences
- Compensation and career patterns
- Job satisfaction and workplace factors
- Relationships between experience, role, and technology choices
- Data quality, missingness, and outlier considerations

## How to Use

1. Open 01_eda.ipynb to review the data preparation and exploratory workflow.
2. Open 02_analysis.ipynb to review the extended analysis and visual insights.
3. Download the required Stack Overflow Developer Survey release from the official source.
4. Place the source files in the local path expected by the notebooks.
5. Run the notebooks in order and review the charts, tables, and observations.

> The notebooks are the source of truth for the survey release, filtering choices, exact findings, and visual outputs.

## Data Source

The project uses the public Stack Overflow Developer Survey. The dataset is not redistributed in this folder. Download the appropriate release from the official [Stack Overflow Developer Survey](https://survey.stackoverflow.co/) website before running the notebooks.

## Limitations

- Survey responses are self-reported and may contain selection or response bias.
- Missing or inconsistent responses can affect comparisons.
- Observed relationships are descriptive and should not be interpreted as causal.
- Results depend on the survey release and the filtering decisions used in the notebooks.
